# Library Management System — Frontend

A web-based Library Management System built with React.js and Material UI. The application provides an interface for managing library members, books, borrowings, and user authentication, communicating with a Node.js and Express REST API backend.

## 🔗 Backend Repository

This frontend communicates with a Node.js and Express REST API backend.

**Backend Repository:** [Library Management System Node Js — Backend](https://github.com/sajid13673/library_management_system-react-express.git)

## Features

- **Authentication** — User registration, login, and authentication management.
- **Member Management** — View, add, edit, and delete library members.
- **Member Activation** — Manage member account activation status.
- **Book Management** — Manage library books and their information.
- **Borrowing Management** — View and manage book borrowing records.
- **Role-Based Access** — Separate functionality for administrators and regular users.
- **Form Validation** — Form handling and validation using Formik.
- **Responsive UI** — Material UI components for a consistent user interface.

> Features listed above should reflect the functionality currently implemented in the application.

## Tech Stack

- **React.js** — Frontend library
- **JavaScript** — Application logic
- **Material UI (MUI)** — UI components and styling
- **React Router** — Client-side routing
- **Axios** — HTTP requests to the backend API
- **Formik** — Form management and validation
- **Day.js / Moment.js** — Date handling

## Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- The Library Management System backend API
